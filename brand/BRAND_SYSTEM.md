- gamified

- robotic

Design language should feel like: **Apple Reminders + Reflect + Arc + Headspace + Superhuman**

## UX PRINCIPLES

1. **SPEECH FIRST** — Typing is fallback.
2. **REDUCE COGNITIVE LOAD** — The app should think FOR the user.
3. **CONVERSATION OVER FORMS** — Avoid rigid structured input whenever possible.
4. **GUIDE GENTLY** — No overwhelming dashboards.
5. **ORGANIZATION SHOULD EMERGE NATURALLY** — Users talk. Yep structures.
6. **INTERFACE SHOULD FEEL ALMOST INVISIBLE** — The focus is mental clarity.

---

## CORE INTERACTION MODEL

Modes:

**1. QUICK MEMO (Stream)**  
Fast capture. Minimal interruption. Brain dump that gets cleaned up by the scrum master agent. Live transcription with draft task extraction. Hit finish → boom, prioritized task list.

**2. CONVERSATION (Flow)**  
Agent actively helps organize and clarify. Asks good questions. Gracefully prods without intruding. Infers dependencies. Sets dates. Schedules smart follow-ups.

Visual distinction between modes is critical:
- **Stream:** minimal UI, stable, quiet
- **Flow:** slightly more alive, responsive, contextual

---

## CRITICAL UX FEATURE: LIVE CONVERSATIONAL CORRECTION

User can say:
- "Actually scratch that." → Task removed
- "No move that to tomorrow." → Date updated
- "That's not important." → Deprioritized
- "Wait prioritize that first." → Priority updated

The UI should:
- visibly adapt live
- feel collaborative
- feel intelligent
- never require manual editing for basic corrections

This is a **KEY differentiator.**
